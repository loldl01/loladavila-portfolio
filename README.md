# Lola Davila Fashion Portfolio — V09

Esta versión rehace la sección de proyectos a partir de tres ideas:

- Petr Menhart: navegación clara, visible y consistente.
- Gougoucore: contraste tipográfico y energía editorial.
- LSKN Personal: ritmo ordenado entre imágenes horizontales y verticales.

## Cambios principales

- Menú completo con una sola tipografía.
- Imágenes reales a pantalla completa al pasar por cada opción del menú.
- Galería sobre una cuadrícula invisible de 12 columnas.
- Ya no hay cuadros flotando de manera aleatoria.
- No hay líneas rojas detrás de las imágenes.
- Los títulos están siempre fuera de las imágenes y no se cortan.
- La composición mantiene variedad sin verse desordenada.
- Puedes agregar más proyectos: el diseño repite automáticamente seis posiciones.
- Fondo negro, cursor rojo y nombre gigante con movimiento.

## Para publicar

Reemplaza en GitHub:

- styles.css
- script.js
- README.md

También puedes subir el ZIP completo.

## Añadir proyectos

Agrega el proyecto en `projects.js`. El nuevo elemento adoptará automáticamente uno de los seis formatos de la galería según su posición.
